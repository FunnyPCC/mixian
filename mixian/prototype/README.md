# 汝职麻辣电线 · 三端前端原型

在项目根目录运行：

```sh
python3 -m http.server 8792 --bind 127.0.0.1 --directory prototype
```

| 独立入口 | 演示凭据 |
| --- | --- |
| [点餐](http://127.0.0.1:8792/) | 无需登录 |
| [商家](http://127.0.0.1:8792/merchant.html) | 密码 `shop123` |
| [骑手](http://127.0.0.1:8792/rider.html) | `rider01` / `rider02`，密码 `demo123` |

三个入口在同一浏览器、同一地址下共享本地订单。建议分三个标签页打开，依次演示下单、人工核款、骑手接单和送达。演示按上海时间从 11:00 开始；预约单在送达段开始前一个履约时长进入接单池，暂停接单后保留有效结算凭据。

新结算的库存预留为 20 分钟。扫码转账时可以点步骤条返回确认订单，修改配送信息会保留原金额、库存和截止时间。米线演示菜品支持选择口味、包装和多选配菜，加价按份计算，不同属性组合共用同一规格库存。

商家可在「设置」编辑点餐首页公告或上传演示收款图。「商品」支持增删标签、批量添加至多四张图片并拖动排序（首图为主图）、配置单选或多选属性和按份加价。商品修改或移除规格仅影响新结算，已有结算和订单保留商品名称、规格、属性、价格和图片快照。

商家可在订单卡片确认到账，并在「进行中」派单或转单给启用中的骑手。骑手可从卡片接单或确认送达，接单前可看楼栋概要和订单备注，接单后才显示收货信息。在「我的」可修改联系资料和密码。

三端的「已完结」包括已完成和已取消订单，详情同时保留每日流水号和完整订单号。商家和骑手可按流水号、订单号或可见的收货手机号搜索；完结统计按完结日期和状态筛选。总收益为所选范围内已完成订单的应付合计，含配送费，不扣除成本。

这不是后端或身份隔离实现。不发起真实支付、退款或拨号，不接微信服务，不部署云开发。清除此站点浏览器数据即可恢复样例。样例商品图为生成摄影，不代表实物。

图标取自 Morphicons Studio 的 [Lucide Outline](https://github.com/guillermolg00/morphicons/blob/main/website/lib/icon-sets/lucide-outline.ts) 和 [Heroicons Fill](https://github.com/guillermolg00/morphicons/blob/main/website/lib/icon-sets/heroicons-fill.ts)，在页面中使用本地 SVG。授权见 `assets/LUCIDE-LICENSE.txt` 和 `assets/HEROICONS-LICENSE.txt`。
