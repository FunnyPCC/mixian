# 三端前端改版方案

独立代理以 critique / audit 检查旧版，优先修复：小屏首屏没有商品、交易状态混淆、任务按钮难找、下拉及技术文本表单不适合手机、演示把手与角色选择侵入产品页面。

| 页面 | 改版方向 |
| --- | --- |
| 用户菜单 | 用店名、营业状态、送达和费用代替大段营销文案。菜图、售价和加购并列，分类贴近商品，购物袋常驻但空时不遮挡内容。 |
| 规格与购物袋 | 展示可售规格和价格，用有选中态的选择控件与数量步进代替纯文字输入。 |
| 确认订单与收款 | 先收货再送达后核价。立即/预约明确分开；转账页突出应付金额与有效期，正式订单仍以提交后的状态为准。 |
| 我的订单与详情 | 区分未提交的结算和正式订单，用状态步骤、送达承诺和本阶段可执行操作代替文字堆叠。 |
| 商家 | 核款和进行中为主要队列，取消单归入历史，不记录线下退款或核款异常。流水号优先，按状态确认到账、派单、转单或取消；收货人与骑手独立展示。 |
| 骑手 | 待接单先看送达范围和时间，接单后显示完整地址；完成记录和在途任务隔离。 |
| 全端 | 独立入口、白色背景、一套线性图标、关键动作有可读标签。移除手机外框、角色切换和测试按钮。 |

交互参考：[DoorDash 的结算与配送说明](https://help.doordash.com/business/s/article/Group-Order-Auto-Checkout?language=en_US)、[DoorDash 订单进度和交付说明](https://developer.doordash.com/en-US/docs/drive/how_to/configure_sms/)。借鉴任务分组与状态反馈，不复刻视觉。
