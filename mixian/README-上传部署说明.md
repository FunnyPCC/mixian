# 麻辣电线校园送餐小程序 · 上传部署说明（保姆级）

这是旧版小程序的参考文档，不是现行原型的发布步骤。当前静态原型不需要部署微信云开发。

这份工程是**完整可运行的微信小程序源码**（聚合收款码 + 店主确认到账 + 跑腿实时接单模式）。你不需要写任何代码，照着下面 9 步操作，全程约 1 小时（不含注册审核等待时间）。

## 准备（一次性）

- 一台**电脑**（Windows/Mac 都行）
- 已完成：小程序注册 + 认证 + 备案（按《小程序注册申请保姆级操作清单》办），拿到 **AppID**（小程序后台 →「开发管理」→「开发设置」→ 开发者ID）
- 手机上有公司收款码图片（收款小精灵那张）

## 第 1 步：安装微信开发者工具

电脑浏览器打开 https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html ，下载「稳定版」，安装后用**小程序管理员的微信**扫码登录。

## 第 2 步：导入本项目

1. 把本压缩包解压到电脑任意文件夹（路径不要带中文最稳妥）；
2. 开发者工具首页 →「+」导入项目 → 选择解压出的 `校园送餐小程序源码` 文件夹；
3. **AppID 填你自己的**（工程里是占位符，必须改）；
4. 后端服务选「微信云开发」→ 点确定。

## 第 3 步：开通云开发

1. 工具栏点「云开发」按钮 → 首次会提示开通 → 创建环境（名字随意，如 `canteen`），选**免费/按量**档位；
2. 开通后在云开发控制台记住**环境 ID**；
3. 如果你账号下有**多个**云环境：打开 `miniprogram/app.js`，把 `wx.cloud.init({ traceUser: true })` 改成 `wx.cloud.init({ env: '你的环境ID', traceUser: true })`。只有一个环境则不用改。

## 第 4 步：上传云函数（后端）

在开发者工具左侧文件树里：

1. 右键 `cloudfunctions/api` →「上传并部署：云端安装依赖」→ 等待提示成功；
2. 右键 `cloudfunctions/closeTimeout` → 同样操作（这个是自动关闭超时未付款订单的，可选但建议传）；
3. `closeTimeout` 的定时触发器：右键该目录 →「上传触发器」（每 5 分钟跑一次）。

**设置口令（必须）**：在云开发控制台为 `api` 云函数配置环境变量 `OWNER_PIN`、`COURIER_PIN`，使用不同且难以猜测的值。不配置则不能通过口令认领对应角色；不要将实际口令写入源码。

## 第 5 步：数据库权限设置

云开发控制台 →「数据库」，你会看到 6 个集合（users、store_settings、categories、dishes、orders、payment_confirmations）。如果没看到，先在模拟器里跑一次第 6 步（店主登录会自动建表），再回来设置：

每个集合 →「权限设置」→ 选「**仅管理端可读写**」。这样所有数据只能经过云函数访问，顾客无法篡改订单。

## 第 6 步：店主初始化（关键）

1. 工具上方点「编译」，左侧模拟器会跑起小程序；
2. 底部 Tab 点「**店主**」→ 输入已配置的店主口令 → 进入店主模式（此时自动写入示例菜单）；
3. 进「设置」页 → **上传公司收款码**（点「上传收款码」选那张收款小精灵图片）；
4. 按需修改：窗口名称、公告、配送费、起送价、配送时段、催单电话、配送模式（抢单/指派）；
5. 进「菜单」页：示例菜品可以直接编辑/删除，把「麻辣电线」真实的菜名、价格、口味/做法/加料配置好。

## 第 7 步：真机预览测试

1. 点工具栏「预览」→ 用管理员微信扫弹出的二维码，小程序跑在手机上；
2. 自测这条链路：点餐页下单 → 支付页看到收款码 → 点「我已付款」→ 店主手机（或模拟器）「对账/订单」出现待确认收款 → 确认到账 → 接单制作 → 出餐完毕 → 跑腿使用已配置的口令加入任务大厅 → 接单 → 已取餐 → 送达；
3. 找 2-3 个室友用「体验版」再测一轮（工具栏「上传」→ 小程序后台「版本管理」→ 设为体验版 → 添加体验成员）。

## 第 8 步：提交审核、发布

1. 工具栏点「上传」，填版本号 1.0.0；
2. 小程序后台 →「版本管理」→ 开发版本 →「提交审核」；
3. 审核信息填写要点（降低被拒概率）：
   - 类目：餐饮服务相关类目（需食品经营许可证）；
   - 简介/备注写「校园餐饮**点单与配送调度**服务，费用通过商家线下收款渠道结算」；
   - 页面里不要出现"在线支付、收银台"字样（本工程文案已按此设计）；
4. 审核通过（一般 24 小时～3 天）→ 点「发布」→ 同学在微信搜索小程序名字即可使用。

## 第 9 步：日常使用（给店主和跑腿）

- **店主**：微信里打开小程序 →「店主」Tab（同一部手机登录过一次就一直有效）→ 高峰时盯「待确认收款」，对照收款小精灵流水点「确认到账」；
- **跑腿**：打开小程序 →「跑腿」Tab → 输口令加入 → 任务大厅 5 秒自动刷新，有新单会收到订阅消息（首次使用记得点"允许"通知授权）；
- **同学**：搜索小程序 → 点餐 → 扫收款码付款（备注订单号）→ 点「我已付款」→ 等送达。

## 常见问题

| 现象 | 原因/解决 |
|------|----------|
| 提示"云函数无返回" | 第 4 步没上传 api 云函数，或云开发没开通 |
| 店主口令输入后报"本店已有店主" | 已有账号认领过店主；使用原账号管理 |
| 顾客下单看不到收款码 | 店主「设置」里还没上传收款码图片 |
| 跑腿大厅没单 | 订单要走完"确认到账→接单制作→出餐完毕"才进大厅；抢单模式下出餐即进大厅 |
| 模拟器可以、真机白屏 | app.js 里 env 没填对环境 ID（多环境时）；或基础库版本过低，在详情→本地设置调高调试基础库 |
| 想换收款码 | 店主「设置」→「更换收款码」，即时生效，进行中订单仍显示下单时的旧码 |
